how it's built

Superbridge isn't a company or a product you sign up for. It's what a community's chat looks like once every platform it uses has been bridged together.

How is that possible? First, a Matrix server gets self-hosted. Then each platform is bridged in through a bot sitting in the chat, talking to mautrix running on that same Matrix server.

From there, every message sent on any platform gets relayed out to all the others through the Matrix relay. Nobody has to leave the app they already have open.
